# Mosaic Vega Example

This example shows that Mosaic works with other charting libraries such as Vega. Right now, the clients in this example hard code a lot of information that could be extracted automatically from a Vega or Vega-Lite specification.

Run this example from the repository root with `bazelisk run //packages/examples/vega-example:dev`.
Source edits reload automatically. Restart the command after changing configuration or dependencies. Use `:build` to build the app and `:preview` to serve the built app.
